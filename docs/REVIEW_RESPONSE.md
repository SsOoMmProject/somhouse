## 그대로 채택하지 않은 제안

- **충돌하면 무조건 max+1:** 이미 Google에 반영됐지만 응답이 유실된 이벤트가 중복될 수 있다. ID 확인을 먼저 한다. 경고 모드 보호는 사용자 동시 편집을 차단하는 잠금이 아니므로 원본의 직접 정렬을 권장하지 않는다.
- **모든 테스트가 mock:** 외부 Google 응답은 모의였지만 기존 서버 테스트는 실제 임시 SQLite와 로컬 HTTP API를 사용한다. 이번에도 실패·순서·재시작 회귀 테스트를 추가했고 OAuth HTTP 오류 해석은 실제 로컬 HTTP 서버로 검증했다. 실제 Google/Nest 연동 검증은 별개다.
- **규격을 무조건 포함 관계로만 비교:** `4단계 52매`를 포함하면서 다른 단계·매수·묶음을 함께 표시하는 결과가 섞일 수 있다. 필수 단위의 충돌과 복수 팩은 계속 제외한다.
- **PR #4 전체 통합:** 서비스 계정, 전체 `spreadsheets` 권한, 별도 Sheets worker, `/api/sheets/sync`, 수동 동기화 버튼은 현재 구조와 중복되어 제외했다. 기존 OAuth `drive.file` 권한으로 원본 보호 설정을 요청할 수 있다. [Sheets batchUpdate 권한](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/batchUpdate)
- **원본 Tasks 자동 수정·삭제:** 음성 원문을 보존하는 정책과 충돌한다. 원본 보존을 화면에서 설명한다.

## 별도 진행할 작업

- 같은 파일의 **수유 현황** 탭은 아직 만들지 않았다. 원본 이력 탭과 현재 상태 탭을 나누고 기존 OAuth worker 하나가 쓰는 설계에는 동의한다. 이번에는 오류 수정과 웹 통계까지 적용했다.
- 정책 페이지 공개, OAuth 콘솔 브랜딩·게시, 사용자 재동의, 실제 계정의 8일 경과 갱신 확인, 맥미니·Pages 배포, Nest 음성 시험은 수행하지 않았다. 이는 코드 변경만으로 검증할 수 없는 운영 절차다.
- Testing의 7일 만료 설명은 공식 문서와 일치한다. 현재 요청하는 Tasks·Drive·Calendar 권한은 기본 프로필만 요청할 때의 예외에 해당하지 않는다. 게시 후 기존 토큰의 수명 연장을 가정하지 않고 재연결로 새 토큰을 받는 절차가 적절하다. 게시와 OAuth 검증은 별개다. - 최근 수유량 버튼, 웹 확인 필요 편집 목록, 상품 별칭 등록 화면, 가족별 OAuth 계정, 충돌 해결 UI는 별도 기능으로 보류했다.
