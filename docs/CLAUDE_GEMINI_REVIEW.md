# Claude의 Gemini 연동 검토

- 검토 기준: `feature/gemini`의 `68646ba`
- 수정 브랜치: `review/claude-gemini` (`origin/feature/gemini`에서 분기)
- 검토자: Claude (Opus 5.5), 2026-11-07

## 결론

구조와 경계는 잘 잡혀 있다. 키·기록 노출이나 인증 우회는 찾지 못했다. 두 가지를 수정했다.

1. Google 응답 대기에 전체 시간 상한이 없었다. (오류 처리·요청 제한)
2. 로그인 확인보다 질문 검증이 먼저 실행됐다. (인증)

## 수정 1. Gemini 호출 전체 기한

**문제.** `HTTPSConnection(timeout=18)`은 연결과 각 읽기에 따로 18초를 적용한다. 응답 헤더 대기와 본문 읽기가 각각 18초에 가깝게 걸리면 전체 시간이 브라우저 제한 25초를 넘을 수 있다. 그러면 브라우저는 먼저 포기하고 "맥미니에 연결하지 못했어요"를 표시한다. 서버의 계정별 동시 요청 슬롯은 Google 응답이 끝날 때까지 남아 있어, 가족이 다시 질문하면 "요청이 많아요"(429)를 받는다.

**수정.** `gemini.py`에 `DEADLINE_SECONDS = 18`을 두고, 기한이 지나면 감시 타이머가 소켓을 `shutdown`해 막힌 읽기를 끊는다. 이 경우 504와 "응답이 늦어지고 있어요"를 돌려준다. 정상 경로와 기존 오류 매핑은 그대로다. 18초는 브라우저 25초보다 짧아, 서버가 항상 먼저 끝내고 슬롯을 비운다.

## 수정 2. 세션 확인 후 질문 검증

**문제.** `POST /api/ai`가 `parse_question`을 세션 확인 전에 실행했다. 유효하지 않은 토큰으로도 400 검증 메시지를 받을 수 있었다. 노출되는 정보는 거의 없지만 다른 API와 순서가 달랐다.

**수정.** 본문은 여전히 잠금 밖에서 읽고(느린 클라이언트가 SQLite 잠금을 잡지 않도록), 세션 확인 직후 질문을 검증한다. 로그아웃된 호출은 항상 401을 받는다.

## 확인했고 문제 없음

- **키 노출**: 키는 `x-goog-api-key` 헤더로만 전송된다. `GET /api/ai`, 오류 메시지, 로그(`log_message` 비활성)에 키가 없다. 설정 파일은 `mkstemp`로 0600 생성 후 원자적으로 교체되고, 그룹·기타 권한이 있으면 로드를 거부한다. 정적 파일은 화이트리스트라 설정 파일과 `gemini.py`가 제공되지 않는다.
- **기록 전송 범위**: 수유는 날짜별 횟수·측정 횟수·ml 합계만, 일정은 날짜별 건수만, 구매는 완료·예정 건수만 보낸다. 메모·병원명·제목 같은 자유 텍스트는 들어가지 않는다. 범위 밖 날짜와 잘못된 날짜는 무시되고, 단위 없는 수유량은 합산에서 빠진다. 사용자가 직접 쓴 질문 자체는 그대로 전송되며 화면에 이 점이 안내된다.
- **`store: false`**: Google 문서상 요청 단위로 로깅을 끄는 최상위 필드이며 프로젝트 설정보다 우선한다. 2026-10-26 이후 생성된 프로젝트는 기본 저장이 켜져 있으므로 이 필드가 필요하다.
- **SQLite 잠금**: Google 대기 전에 잠금과 연결을 해제한다. 기존 테스트가 대기 중 `/api/data` 응답을 검증한다.
- **요청 제한**: 계정별 동시 1건·분당 6회, 시도 시점에 기록하고 `finally`에서 슬롯을 해제한다.
- **Gemini 오류**: 429→429, 401·403→503(관리자 설정 안내), 기타→502, 빈 후보·차단(`promptFeedback`만 있는 응답)·`SAFETY` 종료→502. 사고(thought) 파트는 답변에서 제외된다. 모델 기본 사고 수준이 `minimal`이라 1,024토큰 한도로 답이 비는 위험은 낮다.
- **XSS**: 질문·답변·오류 모두 `textContent`로 표시한다.
- **화면 전환·로그아웃 경합**: `ai` 상태 객체를 요청마다 캡처하고 `ai!==state`면 늦은 응답을 버린다. 로그아웃·401·다른 탭 로그아웃 모두 `showLogin`을 거쳐 상태를 교체한다. AI 패널이 `#content` 밖에 있어 2초 자동 갱신이 입력 중 질문을 지우지 않는다. 실패 시 입력이 유지되고 성공 시에만 비운다.
- **기존 기능**: 기존 API 경로와 백업·로그인 흐름에 변경이 없고 기존 테스트가 모두 통과한다.

## 남은 참고 사항 (수정하지 않음)

- 로그아웃해도 이미 Google로 보낸 요청은 취소되지 않는다. 응답은 버려지지만 사용량은 소비된다.
- 관리자 CLI에서 집계 허용만 바꾸려 해도 키를 다시 입력해야 한다.
- 구매 집계는 날짜 제한 없이 전체 항목을 센다. 의도라면 화면 문구로 충분하다.
- 실제 키·요금제·모델 사용 가능 여부와 휴대폰 화면 검증은 여전히 남아 있다.
