# 솜하우스 서비스 완성 순서

## 확정한 방향

프론트는 GitHub Pages, 공유 저장과 AI 처리는 맥미니, 외부 HTTPS는 Tailscale Funnel을 사용한다. 휴대폰 사용자는 가족 계정으로 로그인해 기록만 관리한다. Firebase는 사용하지 않는다.

- 2026-11-02 사용자 요청: 동시 수정 충돌 처리는 가장 마지막. 같은 항목은 마지막 저장을 적용한다.
- 2026-11-02 사용자 요청: 공유·JSON 내보내기/가져오기는 사용자 기능이 아니다. 추가·수정·삭제가 자동 공유되고 자동 갱신되어야 한다. 백업과 복원은 백엔드 관리자 기능으로 둔다.

## 구현됨

- 수유·병원·일정·구매 CRUD, 빠른 기록, 요약과 검색·필터
- 가족 두 계정, 로그인 만료·로그아웃, 맥미니 SQLite
- 항목별 저장, 실패 시 기존 화면과 입력 유지
- 로그인 전 기존 브라우저 기록 자동 병합. 원본 보존과 중복 방지
- 2초 간격·화면 복귀·네트워크 복구 시 다른 휴대폰 변경 자동 조회
- 편집·검색 입력 중 화면 갱신 보류, 편집창을 닫으면 자동 조회
- 사용자 화면에서 공유·이전·JSON·수동 새로고침·서버 설정 제거
- 변경 전 자동 백업, 맥 관리자 CLI 백업·복원. 웹 복원 API 제거
- 맥 사용자 로그인 시 자동 실행, Tailscale Funnel HTTPS와 Pages 연결

사용자가 두 휴대폰에서 같은 기록이 보이는 것을 확인했다. 이번 자동 갱신 변경은 실제 HTTP API와 프론트 스크립트 두 세션으로 추가·수정·삭제 반영을 검증한다. 브라우저 제어 제한 때문에 실제 UI 자동 검증은 수행하지 못했다.

개인 DB·백업·초기 비밀번호·토큰·API 키는 저장소에 넣지 않는다. 운영법은 README를 참조한다.
