# 솜하우스 서비스 완성 순서

## 확정한 방향

프론트는 GitHub Pages, 공유 저장과 AI 처리는 맥미니, 외부 HTTPS는 Tailscale Funnel을 사용한다. 휴대폰 사용자는 가족 계정으로 로그인해 기록만 관리한다. Firebase는 사용하지 않는다.

- 2026-11-02 사용자 요청: 동시 수정 충돌 처리는 가장 마지막. 같은 항목은 마지막 저장을 적용한다.
- 2026-11-02 사용자 요청: 공유·JSON 내보내기/가져오기는 사용자 기능이 아니다. 추가·수정·삭제가 자동 공유되고 자동 갱신되어야 한다. 백업과 복원은 백엔드 관리자 기능으로 둔다.

## 구현됨

- 수유·병원·일정·구매 CRUD, 빠른 기록, 요약과 검색·필터
- 가족 두 계정, 로그아웃 전까지 로그인 유지, 사용자 비밀번호 변경, 맥미니 SQLite
- 항목별 저장, 실패 시 기존 화면과 입력 유지
- 로그인 전 기존 브라우저 기록 자동 병합. 원본 보존과 중복 방지
- 2초 간격·화면 복귀·네트워크 복구 시 다른 휴대폰 변경 자동 조회
- 편집·검색 입력 중 화면 갱신 보류, 편집창을 닫으면 자동 조회
- 사용자 화면에서 공유·이전·JSON·수동 새로고침·서버 설정 제거
- 변경 전 자동 백업, 맥 관리자 CLI 백업·복원. 웹 복원 API 제거
- 맥 사용자 로그인 시 자동 실행, Tailscale Funnel HTTPS와 Pages 연결

사용자가 두 휴대폰에서 같은 기록이 보이는 것을 확인했다. 이번 자동 갱신 변경은 실제 HTTP API와 프론트 스크립트 두 세션으로 추가·수정·삭제 반영을 검증한다. 브라우저 제어 제한 때문에 실제 UI 자동 검증은 수행하지 못했다.

개인 DB·백업·초기 비밀번호·토큰·API 키는 저장소에 넣지 않는다. 운영법은 README를 참조한다.

## Antigravity CLI 연동

맥미니의 Antigravity CLI를 통해 로그인한 가족의 질문에 답한다. 기본 설정은 질문만 전송한다. 계정 로그인 후 개인정보가 없는 한국어 시험 질문으로 응답을 확인한다. 운영 절차는 [README](../README.md#antigravity-cli-연결)를 참조한다.

AI가 기록을 추가·수정하는 기능을 확장할 때 사용자 확인을 포함한다.

## 네스트 음성 기록과 원본 시트

네스트 허브의 음성 입력은 Google Tasks로 받고, 일반 Google 계정에 공식 데스크톱 OAuth로 Tasks와 Sheets를 연결한다. SQLite는 가족 웹 기록과 전송 이력을 보관한다.

- 웹의 저장과 전송 대기 작업을 SQLite의 한 트랜잭션에 기록한다. Tasks에는 전용 목록에 해당 기록을 복사하고, Sheets에는 각 저장·삭제 이벤트의 원본 데이터를 남긴다.
- 네스트가 쓰는 Tasks 목록에는 음성 인식 결과가 남는다. 정해진 접두어가 붙은 할 일만 가져와, 해석이 확실하면 웹의 수유·병원·일정·구매 화면에 반영한다. 시트에는 해석 전 제목과 Task 데이터를 남긴다.
- Task ID로 음성 중복 등록을 막고, Google 장애가 나면 SQLite에 남긴 이벤트를 대상별로 재시도한다. 원본 시트의 각 행은 이벤트 ID에 대응한다.
- 웹에서는 정리된 기록과 요약을 보여 주고, Google 권한이 있는 가족은 링크로 원본 시트나 Tasks를 열 수 있다.
- 네스트에서 Calendar로 만든 일회성 수유 일정은 제목과 시작 시각으로 해석한다. 웹과 Tasks의 수유 기록은 앱이 만든 전용 수유 캘린더에 표시한다. 기본 캘린더의 원래 일정과 앱 복사본을 분리한다.
- 장보기 음성으로 만든 Tasks는 구매 목록으로 가져오고 원래 Task에 가격 검색 링크를 덧붙인다. 상품과 규격을 지정하고 검색 키를 연결하면 확인 가능한 결과의 표시가를 비교한다.

코드와 모의 검증이 준비됐다. 운영 적용 전 한국어 네스트 실기기가 제목을 보존하는지 확인하고, 운영 Google 계정의 OAuth 동의 후 가짜 수유 한 건을 네스트와 웹에서 각각 입력해 전송과 재조회를 검증한다. [연결 절차](../README.md#네스트-허브google-tasks원본-시트-연결)
